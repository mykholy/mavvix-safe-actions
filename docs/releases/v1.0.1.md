# Mavvix Safe Actions v1.0.1

**Distribution and documentation patch for the v1.0.0 stable API.** No changes to runtime PHP classes, selection behavior, authorization logic, database schema, or public method signatures.

## Updated for Packagist and Filament discovery

- Richer Composer metadata: accurate purpose, project homepage, actual maintainer, issue tracker, source, security policy and focused discovery keywords.
- Professional README: main CI/browser badges, version/license/platform badges, practical feature/benefit comparison, and clear Composer installation guidance.
- Dedicated [Packagist submission checklist](https://github.com/mykholy/mavvix-safe-actions/blob/v1.0.1/docs/packagist-submission.md) and [Filament plugin directory copy](https://github.com/mykholy/mavvix-safe-actions/blob/v1.0.1/docs/filament-plugin-listing.md).
- GitHub bug/feature report and pull request templates, aligned with fail-closed security expectations.
- Corrected stale pre-alpha terminology in historical documentation and contribution guidance.

## Installation

Once indexed on Packagist:

```bash
composer require 'mykholy/mavvix-safe-actions:^1.0'
php artisan vendor:publish --tag=safe-actions-migrations
php artisan migrate
```

For VCS installation before Packagist indexing, see the [README](https://github.com/mykholy/mavvix-safe-actions/blob/v1.0.1/README.md#installation).

## Security disclosure

Version 1.0.1 is a docs and distribution metadata patch over 1.0.0, whose [first-party review](https://github.com/mykholy/mavvix-safe-actions/blob/v1.0.1/docs/security-review-v1.0.0.md) is documented. It has **NOT received independent security sign-off**, human screen-reader certification or production-like load qualification. Scope remains limited to bounded, database-only Eloquent/Filament 5 actions in one connection; external side effects are not transactionally reversible.

See [security policy](https://github.com/mykholy/mavvix-safe-actions/blob/v1.0.1/SECURITY.md).
